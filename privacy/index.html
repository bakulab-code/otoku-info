プライバシーポリシー

制定・最終更新日：2026年11月2日

DAISUKE UEDA（以下「運営者」）は、iPhoneアプリ「おトク通知」（以下「本アプリ」）および本サイトで取り扱う情報について、次のとおり定めます。

1. 取り扱う情報と目的

本アプリは、氏名やメールアドレスによるアカウント登録を必要としません。ただし、通知配信とサービスの運用に必要な以下の情報を取り扱います。

通知用の端末・アプリ識別情報
インストールごとの識別子、Firebase Installation ID、通知配信に必要なトークンや認証情報を利用します。通知先の識別、設定の安全な更新、不正アクセス防止のために使います。
企業選択・通知設定
選択した企業、通知をしないシリーズ、通知するタイミング、通知の有効・無効、設定の更新情報を端末とサーバーに保存します。希望に沿った表示・通知のために使います。
通知の配信・処理記録
登録や設定更新の日時、配信対象、送信結果・エラー、重複送信を防ぐ記録などを保存します。通知の配信、障害調査、重複や不正利用の防止のために使います。
通信・安全性に関する情報
サーバーや外部サービスへの通信に伴い、IPアドレス、アクセス日時、リクエスト情報、端末・アプリの真正性を確認する情報などが処理・記録されることがあります。通信の提供、安全性の確認、障害対応のために使います。
お問い合わせ情報
メールアドレス、メール本文、任意で提供された機種・バージョン・画像などを受け取ります。問い合わせへの回答、問題の調査・解決のために使います。

位置情報、連絡先、写真ライブラリ、決済情報を本アプリが取得する機能はありません。広告識別子（IDFA）による追跡、Firebase Analytics、広告SDK、利用者ごとの外部リンクのクリック計測は導入していません。

2. 外部サービスの利用

機能の提供に必要な範囲で、次のサービスを利用します。これらの事業者による処理・保管には各サービスの規約・ポリシーも適用され、日本国外で処理・保管される場合があります。

  • Supabase：キャンペーン情報の配信、通知用端末登録・設定・配信記録の保存と処理。プライバシーポリシー
  • Google Firebase：Cloud Messaging・Installationsによる通知配信、App Checkによる正規アプリからの通信確認。必要な識別子、通知情報、検証情報などを処理します。プライバシーとセキュリティ
  • Apple：APNsによるiPhoneへの通知配信、App Attestによるアプリの真正性確認。プライバシーポリシー
  • GitHub Pages：本サイトの配信。サイトへのアクセス時、GitHubは安全性のためIPアドレスなどを記録します。本サイト独自のアクセス解析・広告・Cookieによる追跡は導入していません。プライバシーステートメント
  • Google Gmail：お問い合わせメールの受信・保管・返信。プライバシーポリシー

キャンペーン情報の収集・整理には外部AIサービスを利用しますが、利用者の端末識別情報、企業選択、通知設定をその検索・整理処理に渡すことはありません。

3. 外部リンクとアフィリエイト

本アプリから公式サイトや販売・予約サイトなどへ移動した後の情報の取り扱いは、移動先のポリシーに従います。購入・予約の手続きや決済は移動先で行われ、運営者は決済情報を取得しません。

承認・設定が済んだ一部のリンクには、購入・予約などに応じて運営者が報酬を受け取るアフィリエイトを利用する場合があります。対象リンクには利用の旨を表示します。リンク先や提携事業者が、Cookieなどを用いて成果を計測する場合があります。

本アプリからアフィリエイトURLに端末識別子、Firebase Installation ID、通知トークンなどを付加しません。他のアプリやサイトの閲覧履歴を使った広告選定は行わず、広告専用の通知も送りません。採用する方式に応じて、必要な説明・同意を整備します。

4. 保存期間

  • 通知用端末登録は、最後に正常な登録・設定更新を行ってから1年を経過した後、日次処理で関連する端末別データとともに削除します。通知の送信だけでは、この期限を延長しません。
  • 配信先が無効と判明した登録は、検知から30日を経過した後に削除します。初期登録が完了しなかったものは7日を経過した後に削除します。
  • 日ごとの通知配信処理の記録は原則7日間保持します。重複送信防止の記録は、関連する今後の受付・販売開始がなくなった後の整理処理で削除します。
  • お問い合わせ情報は、回答・問題解決・必要な対応記録のために保持し、不要になった情報は順次削除します。

アプリを削除しても、サーバー側ですぐに削除を検知できるとは限りません。端末登録は上記の条件で削除されます。障害復旧用のバックアップや外部サービスの運用ログには、本番データとは別の保持期間が適用されることがあります。

5. 通知の停止・情報に関するご相談

iPhoneの設定から本アプリの通知を無効にできます。本アプリの設定から、選択企業や通知タイミングも変更できます。サーバーへの設定反映には通信が必要です。通知を許可しなくても、企業選択や情報の閲覧はできます。

情報の開示・訂正・利用停止・削除に関するご相談は、下記の窓口へご連絡ください。メールアドレスと端末登録は自動では結び付かないため、対象情報の特定とご本人の確認に必要な範囲で確認をお願いすることがあります。

6. 安全管理と第三者への提供

通信の暗号化、アクセス権限の制限、アプリの真正性確認などにより、情報の漏えいや不正利用の防止に努めます。利用者の情報を販売しません。上記の機能提供のための委託、利用者の同意がある場合、法令に基づく場合などを除き、個人情報を第三者に提供しません。

7. ポリシーの変更

サービス内容や法令等の変更に応じて本ポリシーを改定することがあります。改定時には本ページの更新日を変更し、重要な変更については、内容に応じた方法でお知らせします。
