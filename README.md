GitHub Pagesで公開する静的HTML/CSSのみのサイトです。
GitHub Pagesの公開元は `main` ブランチのルートを使用します。
Node.js、ビルド、外部JavaScript、アクセス解析、フォーム用サーバーは不要です。

アプリ本体のソースコード、端末情報、秘密情報、内部運用資料はここに含めません。
公開ページの文章を更新してmainへpushすると、GitHub Pagesに反映されます。
実際のデータの取り扱いを変更した際は、ポリシーとApp Storeのプライバシー情報も見直してください。
